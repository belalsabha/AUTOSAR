# Door Lock Indication — AUTOSAR Integration

## Overview

This project documents the development and integration of a Door Lock Indication application within an AUTOSAR/OSEK-based operating system environment.

The work covers the process from designing the system and creating ARXML configuration files to integrating the application with the OS, configuring tasks, and verifying the resulting behavior.

Rather than presenting only the final implementation, this repository documents the engineering workflow, configuration decisions, integration steps, and debugging process.
