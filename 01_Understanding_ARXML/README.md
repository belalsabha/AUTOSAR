# Understanding ARXML, SWCs, and RTE

This section covers the fundamentals of AUTOSAR application software configuration through practical ARXML exercises and RTE-related projects.

## Labs

1. **MyDataTypes_Project:** Defining and configuring AUTOSAR data types using ARXML.
2. **L1 — SWC Types:** Understanding AUTOSAR Software Component types.
3. **L2 — Sender-Receiver Interface:** Configuring data communication between SWCs.
4. **L3 — Client-Server Interface:** Configuring operation-based communication.
5. **L4 — Compositions:** Connecting components using Assembly and Delegation Connectors.
6. **L5 — Runnables:** Defining runnable entities and their behavior.
7. **L6 — RTE Events:** Configuring events that trigger runnable execution.
8. **Door Lock Indicator:** Applying SWC and RTE concepts in a practical embedded project.

## Focus

- ARXML structure and configuration
- SWC interfaces and communication
- Runnables and RTE Events
- RTE configuration and code generation

Each lab will include its objective, relevant configuration files, and practical observations where applicable.
