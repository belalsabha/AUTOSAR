# AUTOSAR Application Software Layer

This section covers practical AUTOSAR Application Layer development, including ARXML configuration, Software Components (SWCs), communication interfaces, Runnables, and RTE Events.

## Projects

- **MyDataTypes Project:** AUTOSAR data type definitions and configuration.
- **AUTOSAR ASWL Labs:** Practical exercises covering SWC types, Sender-Receiver and Client-Server interfaces, Compositions, Runnables, and RTE Events.
- **Door Lock Indicator:** An application-level project demonstrating AUTOSAR configuration and RTE integration.

## Focus Areas

- ARXML configuration and validation
- Software Components and communication interfaces
- Runnables and RTE Events
- RTE configuration and code generation

## Tools

- C and ARXML
- ARTOP 
- AUTOSAR XSD schemas
