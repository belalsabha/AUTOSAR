# AUTOSAR — Practical Learning & Implementation

## Overview

A collection of hands-on AUTOSAR projects and embedded systems labs, covering ARXML configuration, Application SWCs, RTE, OSEK-VDX OS concepts and AUTOSAR OS configuration.

The projects focus on implementation, debugging and practical verification using STM32 microcontrollers.

## Repository Contents

- **01 — Understanding ARXML:** SWC Types, SR/CS Interfaces, Compositions, Runnables, RTE Events, and Door Lock Indicator.
- **02 — OSEK-VDX OS:** Task Scheduling, Resources, Counters, Alarms, Events, ISRs, and Hooks using Trampoline OS.
- **03 — AUTOSAR Integration:** Integrating the Door Lock application with OS configuration.
- **04 — ArcCore Configuration:** ARXML-based OS configuration, code generation, debugging, UART, GPIO, and Alarms.

## Tools & Technologies

- C and ARXML
- STM32F407 and STM32F103C8T6
- Trampoline OS and ArcCore AUTOSAR Stack
- Keil µVision and ARTOP (ARUNIT)

Each section includes practical labs, implementation details and debugging observations.
