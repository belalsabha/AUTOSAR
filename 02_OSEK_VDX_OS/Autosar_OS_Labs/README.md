# AUTOSAR OS Labs

## Overview

This project contains operating system source code, supporting modules, configuration tools, examples, tests, and practical learning exercises.

The `learn-in-depth` directory contains C programming labs accompanied by Keil µVision simulation screenshots.

## Repository Structure

- `autosar/` — AUTOSAR-related files.
- `com/` — Communication-related modules.
- `debug/` — Debugging support.
- `documentation/` — Project documentation.
- `examples/` — Example applications.
- `extra/` — Additional resources.
- `goil/` — Configuration and code-generation tools.
- `ioc/` — Inter-OS-Application Communication modules.
- `learn-in-depth/` — Practical C labs and simulation results.
- `libraries/` — Supporting libraries.
- `machines/` — Platform and target definitions.
- `make/` — Build system files.
- `os/` — Operating system source files.
- `tests/` — Test files.
